# 武忠祥课程 → 数二真题解析

这批材料的最终用途是解释已经收集在 `chapters/` 的真题，而不是增编题库。两套课程分别保存原PDF和逐课理解，处理记录与真题匹配依据可验证、可继续。

- [十七堂课](17/README.md)：专题方法与综合题路径。
- [选填题](xt/README.md)：选项辨析、反例、几何与计算捷径。
- [处理与复核规范](process/README.md)：如何把课程内容用于真题，以及何时不能声称已经复现。

## 解析采用标准

**同题复现**：题干、条件一致，原页公式与手写步骤已经视觉核对，按板书路径写解答，另标必要的补足说明。**同法迁移**：题干不同，但结构和条件相符，明确标注方法来自哪节哪页，具体计算是GPT推导。**待核**：缺少来源、公式不清或条件不匹配时，保留疑点，不套老师名义。

板书未记录的口头判断无法仅靠PDF完整恢复。目标是逐题核对后尽可能忠实复现可见路径，而不是预先承诺每道真题都能完全还原老师本人的现场讲法。
