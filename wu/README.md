## 解析采用标准

**同题复现**：题干、条件一致，原页公式与手写步骤已经视觉核对，按板书路径写解答，另标必要的补足说明。**同法迁移**：题干不同，但结构和条件相符，明确标注方法来自哪节哪页，具体计算是推导补充。**待核**：缺少来源、公式不清或条件不匹配时，保留疑点，不套老师名义。

板书未记录的口头判断无法仅靠 PDF 完整恢复。目标是逐题核对后尽可能忠实复现可见路径，而不是预先承诺每道真题都能完全还原老师本人的现场讲法。
