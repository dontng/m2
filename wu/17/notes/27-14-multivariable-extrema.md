## 一、本课定调 & 第一眼路由表

**核心定调**：极值是**局部邻域比较**，最值是**指定集合全局比较**。考场三大铁动作：**无条件先看判别式（$AC-B^2=0$ 立刻切回定义）、条件极值用拉格朗日（别忘因子为零分支和几何端点）、闭域最值严格走“内部 + 边界”三步流**。

| 第一眼触发特征 | 首选 / 秒杀（【解1】） | 兜底通解（【解2】） | 放行红线（踩中必丢分） |
| :--- | :--- | :--- | :--- |
| **无条件极值（显式 / 全微分）**（`p.2, 7, 9`） | 令 $f_x=f_y=0$ 找驻点，算 $A=f_{xx},B=f_{xy},C=f_{yy}$，用 $AC-B^2$ 判别 | $AC-B^2=0$ 或函数不可导时，**回到极值定义**比 $f(x,y)$ 与 $f(x_0,y_0)$ 差号 | **$AC-B^2=0$ 绝不可判“无极值”**！不可导点也可能是极值点（`p.2`） |
| **极限式判定某点极值**（`p.5` 例1） | 去分母写 $f(x,y)-f(0,0)=\text{主部}(>0)+o(\text{主部})$，利用连续性与保号性秒杀 | 沿不同方向如 $y=kx$ 或 $y=x^2$ 验证符号是否同号 | 仅由单点极限式**不可默认二阶偏导存在**去套 $AC-B^2$ |
| **含交叉/分离变量 $f(x)g(y)$ 或条件极值选择题**（`p.6, 8`） | 直接算 $AC-B^2=f''(0)g''(0)f(0)g(0)$ 看符号；条件极值写驻点方程 $\nabla f+\lambda\nabla\varphi=0$ 判零因子 | 取特例函数验证选项（如 $f(x)=1\pm x^2$） | 分开处理 $A>0$（极小）与 $A<0$（极大），符号勿反（`p.6`） |
| **有界闭域 $D$ 上最值**（`p.4, 13–16`） | **闭域三步法**：①内部驻点 ②边界最值（能直接代换消元或参数方程绝不硬算乘数法 `p.13,15`）③比大小 | 边界用拉格朗日乘数法（适合椭圆带 $xy$ 交叉项，`p.16`）；调和/双曲型（`p.12`）直接判边界取最值 | 边界分段点、角点及坐标非负约束端点（`p.19`）**必须单独代入比较** |
| **应用题 / 不等式转条件极值**（`p.18–20`） | 距离最值先去掉根号优化 $d^2=x^2+y^2$；不等式转化为给定约束下的最值上界（`p.20`） | 约束明显可解出单变量时，代入化为一元最值 | 消去参数 $\lambda$ 时若除以 $x$ 或 $1+\lambda$，**必须讨论为零的分支**（`p.17`） |

## 二、核心铁律与 `→ / ↛` 概念红线 / 极简反例

| 命题推导方向 | 逻辑结论 | 极简反例 / 武氏板书红线（`p.2–4`） |
| :--- | :---: | :--- |
| $(x_0,y_0)$ 为极值点 $\longrightarrow (x_0,y_0)$ 为驻点 | **`↛` 打叉** | 需加**“一阶偏导存在（可导）”**前提；反例：$f(x,y)=|x|+|y|$ 在 $(0,0)$ 取极小值但偏导不存在（`p.2`）。 |
| $(x_0,y_0)$ 为驻点 $\longrightarrow (x_0,y_0)$ 为极值点 | **`↛` 打叉** | 反例：$f(x,y)=xy$ 在 $(0,0)$ 满足 $f_x=f_y=0$，但在第一、三象限为正，二、四象限为负，是鞍点非极值点（`p.2`）。 |
| 驻点处 $AC-B^2=0 \longrightarrow$ 无极值 | **`↛` 打叉** | **“不一定，一般用定义判定”**（`p.2`）：$x^4+y^4$（极小值）、$-x^4-y^4$（极大值）、$x^4-y^4$（无极值）均满足 $AC-B^2=0$。 |
| 连续函数 $u(x,y)$ 在 $D$ 内满足 $u_{xx}+u_{yy}=0$ 且 $u_{xy}\neq 0 \longrightarrow$ 最值均在边界 $\partial D$ 上取得 | **`→` 成立** | `p.12` 例1：此时内部任意驻点必有 $A=-C \implies AC-B^2 = -A^2-B^2 < 0$（因为 $B=u_{xy}\neq 0$），内部绝无极值点，故最值必落边界！ |
| 条件极值求得拉格朗日驻点 $\longrightarrow$ 只需再套 $AC-B^2$ 即可判极大/极小 | **`↛` 打叉** | **$AC-B^2$ 仅适用于无条件极值**！条件极值只能靠闭域有界性比大小、二阶全微分在切方向限制或代入消元判别。 |

## 三、高频母题 & 一题多解实战拆解

### 母题 1：极限型多元函数局部保号判极值（`p.5` 例1）

> 已知 $f(x,y)$ 在 $(0,0)$ 某邻域内连续，且 $\lim_{\substack{x\to 0\\y\to 0}}\frac{f(x,y)-xy^2}{1-\cos\sqrt{x^2+y^2}}=1$，则 $(0,0)$ 是 $f(x,y)$ 的（ ）。  
> （A）非极值点 （B）极大值点 （C）极小值点 （D）无法判断

- **【秒杀推导】**：
  1. 由连续性及分母 $\to 0$ 知 $f(0,0)=0$。分母等价 $1-\cos\sqrt{x^2+y^2}\sim\frac{1}{2}(x^2+y^2)$，故
     $$\lim_{\substack{x\to 0\\y\to 0}}\frac{f(x,y)-xy^2}{\frac{1}{2}(x^2+y^2)} = 1 \implies f(x,y) = \frac{1}{2}(x^2+y^2) + xy^2 + o(x^2+y^2).$$
  2. 注意高阶项吸纳：$\left|\frac{xy^2}{x^2+y^2}\right| \le \frac{r^3}{r^2}=r \to 0$，即 $xy^2=o(x^2+y^2)$！因此
     $$f(x,y) = \frac{1}{2}(x^2+y^2) + o(x^2+y^2) > 0 = f(0,0) \quad (\text{去心邻域内}).$$
     故 $(0,0)$ 为**极小值点**，选 **（C）**。
- **【经典 0 分错法】**：看到分子有 $-xy^2$ 或没有显式写出二阶偏导，误选（D）“无法判断”；或者错误声称“$f_{xx}(0,0)=1$”。

### 母题 2：偏导反求函数的双轨极值策略（`p.10–11` 例6）

> 已知 $f(x,y)$ 满足 $f''_{xy}(x,y)=2(y+1)e^x,\ f'_x(x,0)=(x+1)e^x,\ f(0,y)=y^2+2y$，求 $f(x,y)$ 的极值。

- **【解1】先偏积分还原 $f(x,y)$ 再判极值（`p.10`）**：
  1. 对 $y$ 积分：$f'_x(x,y)=(y+1)^2 e^x + \varphi(x)$，代入 $f'_x(x,0)=(x+1)e^x$ 得 $\varphi(x)=xe^x$。
  2. 对 $x$ 积分：$f(x,y)=(y+1)^2 e^x + (x-1)e^x + \psi(y)$，代入 $f(0,y)=y^2+2y$ 得 $\psi(y)=0$，故 $f(x,y)=(x+y^2+2y)e^x$。
  3. 后续求驻点得 $(0,-1)$，$A=1, B=0, C=2 \implies AC-B^2=2>0, A>0$，极小值为 $f(0,-1)=-1$。
- **【解2】不求 $f(x,y)$ 直接由一阶偏导锁定驻点与二阶导（`p.11`）**：
  因为只求极值（仅极值点的值需要代入或局部积分），在求出 $f'_x=(y+1)^2 e^x+xe^x$ 后，直接从 $f(0,y)=y^2+2y$ 知 $f'_y(0,y)=2y+2$，结合 $f''_{xy}$ 对 $x$ 积分可得 $f'_y=(2y+2)e^x$，立即解驻点 $(0,-1)$ 并算 $A,B,C$。

### 母题 3：有界闭域最值三解法大比武（`p.13–15` 例2 & `p.16` 例3）

#### 例 2（`p.13–15`）：已知全微分 $\mathrm{d}z=2x\,\mathrm{d}x-2y\,\mathrm{d}y$ 且 $f(1,1)=2$，求 $f$ 在椭圆域 $D=\{(x,y)\mid x^2+\frac{y^2}{4}\le 1\}$ 上的最值
- 先恢复原函数 $f(x,y)=x^2-y^2+2$，内部唯一驻点为 $(0,0)$，且 $f(0,0)=2$。边界 $x^2+\frac{y^2}{4}=1$ 有三条通道：
  - **【解1】消元化一元（`p.13` 秒杀）**：边界上 $y^2=4-4x^2\ (-1\le x\le 1)$，代入得 $z=5x^2-2$，边界最大 $3\ (x=\pm 1)$，最小 $-2\ (x=0)$。
  - **【解2】拉格朗日乘数法（`p.14`）**：构造 $L=x^2-y^2+2+\lambda(x^2+\frac{y^2}{4}-1)$，由 $2x(1+\lambda)=0$ 与 $y(-2+\frac{\lambda}{2})=0$ 分支得 $(0,\pm 2), (\pm 1,0)$。
  - **【解3】三角参数方程（`p.15`）**：令 $x=\cos t,\ y=2\sin t$，则 $z=\cos^2 t - 4\sin^2 t + 2 = 3 - 5\sin^2 t \in [-2, 3]$。
  - **第三步合并比较**：对比内部 $f(0,0)=2$ 与边界最值，得全域最大值 $3$，最小值 $-2$。

#### 例 3（`p.16`）：带交叉项 $xy$ 的椭圆域最值（行列式消 $\lambda$）
- 当 $f(x,y)=x^2+12xy+2y^2$ 在 $4x^2+y^2\le 25$ 上求边界极值时，无法直接消去单变量平方，用拉格朗日得齐次线性方程组：
  $$\begin{cases}(1+4\lambda)x+6y=0,\\ 6x+(2+\lambda)y=0.\end{cases}$$
  **因为 $(x,y)$ 在椭圆上不能同时为 $0$（必有非零解）**，直接令系数行列式 $\begin{vmatrix}1+4\lambda & 6\\ 6 & 2+\lambda\end{vmatrix}=0$ 秒出 $\lambda_1=2,\ \lambda_2=-\frac{17}{4}$，回代椭圆方程出 4 个候选点，最大值 $\frac{425}{4}$！

### 母题 4：约束端点漏算红线与拉格朗日证不等式（`p.18–20` 例5、例6）

- **例 5（`p.18–19`）**：求曲线 $x^3-xy+y^3=1\ (x\ge 0, y\ge 0)$ 上点到原点的最值距离。
  - **化简目标**：优化 $x^2+y^2$（省去根号）。
  - 在 $x>0,y>0$ 内部乘数法解得 $y=x \implies (1,1)$，距离 $\sqrt{2}$。
  - **关键红线（`p.19`）**：题设限制 $x\ge 0, y\ge 0$，**必须补充检查端点 $x=0, y=1$ 与 $y=0, x=1$**，得距离 $1$！故最长 $\sqrt{2}$，最短 $1$（若漏查端点就找不到最短距离 $1$！）。
- **例 6（`p.20`）Young 不等式证明**：已知 $p>1, \frac{1}{p}+\frac{1}{q}=1, x,y>0$，证 $xy\le \frac{x^p}{p}+\frac{y^q}{q}$。
  - **武氏转化**：固定 $\frac{x^p}{p}+\frac{y^q}{q}=k>0$，转化为证明条件最值 $xy \le k$。乘数法求唯一驻点 $x=k^{1/p}, y=k^{1/q}$，此时 $xy=k^{1/p+1/q}=k$ 即为最大值。
