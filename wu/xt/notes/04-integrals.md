## 一、本课定调 & 选填第一眼秒杀路由表

《选填（4）》集中处理一元积分选填的高频陷阱：定积分大小比较、变限积分在间断点处的可导性、反常积分敛散性判定，以及利用对称性与 Wallis 点火公式快速算定积分。

| 第一眼触发特征 | 【解1】首选 / 秒杀路由 | 【解2】直接法严谨兜底 | 放行红线（0 分雷区） |
| :--- | :--- | :--- | :--- |
| **连续/可积/原函数/可导四性辨析** | 脑内直接调出**“可导 $\to$ 连续 $\to$ 可积 / 有原函数”三角图**（`p.10`） | 用 $\operatorname{sgn}(x)$ 否连续、达布导数函数否可积 | **可积 $\not\leftrightarrow$ 存在原函数**（两方向均打叉，`p.10`） |
| **给定 $f''>0$（或凹凸性）比积分大小** | **几何弦线切线法 + 赋二次特例**（如 $f=2x^2-1$）秒排（`p.16`） | 分段构造弦线不等式或二次积分中值 | 区间跨正负时，**分段弦线须分别比较**（`p.16`） |
| **变限积分 $\int_a^x f(t)\,\mathrm{d}t$ 间断点性态** | **三行硬表秒判**：连续/可去 $\to$ 可导；跳跃 $\to$ 连续不可导（`p.20`） | 算出 $x_0$ 左右极限再按导数定义求 $F'_-(x_0),F'_+(x_0)$ | 在可去间断点处 $F'(x_0)=\lim_{x\to x_0}f(x)\neq f(x_0)$，故 $F$ **非原函数**（`p.20`） |
| **反常积分 $\int_a^{+\infty}$ 或瑕积分判敛散** | **同阶 $p$-积分比较 + $e^{x}$ 压倒一切幂函数**（`p.33–34`） | 凑微分直接算出原函数取极限 | 含多个无穷限或瑕点必须**拆开各自独立收敛** |
| **对称区间 / 三角幂次 / 函数方程定积分** | **奇零偶倍** + **Wallis 点火公式** + **$\int_0^\pi x f(\sin x)\,\mathrm{d}x$**（`p.41`） | 平移变量构造变限积分 $F(x)=\int_x^{x+T}f(t)\,\mathrm{d}t$（`p.57`） | 跨原函数间断点（如 $\tan x$ 过 $\frac{\pi}{2}$）**禁直接代牛顿-莱布尼茨** |
| **绕一般直线旋转体体积** | 直接套**二重积分万能公式** $V=2\pi\iint_D r(x,y)\,\mathrm{d}\sigma$（`p.41` 公式，例题见 `p.54–55`；斜轴万能式见 `专题11 p.4`） | 坐标旋转变换后用微元圆盘法 | 万能公式要求旋转轴**不穿过区域 $D$ 内部** |

## 二、核心 `→ / ↛` 概念红线 & 极简反例库

| 命题推导方向 | 逻辑结论 | 武氏极简反例 / 板书实证 |
| :--- | :---: | :--- |
| $f$ 在 $[a,b]$ 可导 $\to$ 连续 $\to$ 可积 | **单向 `→`** | 反向全 **`↛`**：$\|x\|$ 连续不可导；$\operatorname{sgn}(x)$ 有限间断可积不连续（`p.10`）。 |
| $f$ 在 $[a,b]$ 可积 $\longleftrightarrow f$ 在 $[a,b]$ 存在原函数 | **双向皆 `↛`** | $\operatorname{sgn}(x)$ 可积但无原函数（违背达布介值性）；存在导数震荡无界函数有原函数却不可积（`p.10`）。 |
| $f$ 在 $x_0$ **跳跃间断** $\longrightarrow F(x)=\int_a^x f(t)\,\mathrm{d}t$ 连续但不可导 | **`→` 成立** | $F'_+(x_0)=f(x_0^+)\neq f(x_0^-)=F'_-(x_0)$；而**可去间断**使 $F$ 可导但 $F'(x_0)\ne f(x_0)$（`p.20`）。 |
| 非负连续 $f$ 使 $\int_0^{+\infty}f^2(x)\,\mathrm{d}x$ 收敛 $\longrightarrow \int_0^{+\infty}f(x)\,\mathrm{d}x$ 收敛 | **`↛` 打叉** | 极简反例：$f(x)=\frac{1}{x+1}$ 在 $[0,+\infty)$ 平方可积但本身积分发散（`p.39`）。 |
| 非负连续 $f$ 使 $\int_0^{+\infty}f(x)\,\mathrm{d}x$ 收敛 $\longrightarrow \exists p>1,\ \lim_{x\to+\infty}x^pf(x)$ 存在 | **`↛` 打叉** | 极简反例：$f(x)=\frac{1}{(x+2)\ln^2(x+2)}$ 可积，但对任意 $p>1$ 有 $x^p f(x)\to+\infty$（`p.39`）。 |

## 三、高频选填母题双轨拆解

### 母题 1：凸性与端点值比定积分大小（2017 年 2 · `p.16` 例 11）
> 设二阶可导函数 $f(x)$ 满足 $f(1)=f(-1)=1,\ f(0)=-1$，且 $f''(x)>0$，则（　）  
> （A）$\int_{-1}^1 f(x)\,\mathrm{d}x > 0$　（B）$\int_{-1}^1 f(x)\,\mathrm{d}x < 0$　（C）$\int_{-1}^0 f(x)\,\mathrm{d}x > \int_0^1 f(x)\,\mathrm{d}x$　（D）$\int_{-1}^0 f(x)\,\mathrm{d}x < \int_0^1 f(x)\,\mathrm{d}x$

- **【解1 · 考场 10 秒排除法（`p.16` 解 2）】**：
  - 取最简满足三条件且 $f''>0$ 的抛物线 $f(x)=2x^2-1$：
    - $f(\pm 1)=1,\ f(0)=-1,\ f''(x)=4>0$；
    - 偶函数立刻排除 **（C）（D）**，算 $\int_{-1}^1 (2x^2-1)\,\mathrm{d}x = 2\left(\frac{2}{3}-1\right)=-\frac{2}{3}<0$ → 秒选 **（B）**！
- **【解2 · 几何弦线法兜底（`p.16` 解 1）】**：
  - 因 $f''(x)>0$（下凹），在 $[-1,0]$ 与 $[0,1]$ 上曲线 $f(x)$ 严格位于连接 $(-1,1),(0,-1)$ 与 $(0,-1),(1,1)$ 的两条弦线 $g(x)=2|x|-1$ **下方**，而 $\int_{-1}^1 (2|x|-1)\,\mathrm{d}x=0$，故 $\int_{-1}^1 f(x)\,\mathrm{d}x < 0$。

### 母题 2：反常积分概念与极限判别正误（2024 年 2 · `p.39` 例 6）
> 设非负函数 $f(x)$ 在 $[0,+\infty)$ 上连续，给出以下 3 个命题：  
> ① 若 $\int_0^{+\infty}f^2(x)\,\mathrm{d}x$ 收敛，则 $\int_0^{+\infty}f(x)\,\mathrm{d}x$ 收敛；  
> ② 若存在 $p>1$，使得 $\lim_{x\to+\infty}x^p f(x)$ 存在，则 $\int_0^{+\infty}f(x)\,\mathrm{d}x$ 收敛；  
> ③ 若 $\int_0^{+\infty}f(x)\,\mathrm{d}x$ 收敛，则存在 $p>1$，使得 $\lim_{x\to+\infty}x^p f(x)$ 存在。  
> 真命题个数为：（A）$0$　（B）$1$　（C）$2$　（D）$3$

- **【解1 · 反例击穿 + 比较判别（`p.39`）】**：
  - **① 错**：取 $f(x)=\frac{1}{x+1}$，$\int_0^{+\infty}\frac{\mathrm{d}x}{(x+1)^2}=1$ 收敛，但 $\int_0^{+\infty}\frac{\mathrm{d}x}{x+1}=+\infty$ 发散；
  - **② 对**：设 $\lim_{x\to+\infty}\frac{f(x)}{1/x^p}=A\ge 0$（有限），由比较法极限形式及 $p>1$ 知 $\int_0^{+\infty}f(x)\,\mathrm{d}x$ 收敛；
  - **③ 错**：取 $f(x)=\frac{1}{(x+2)\ln^2(x+2)}$，显式积分得 $-\frac{1}{\ln(x+2)}\big|_0^{+\infty}=\frac{1}{\ln 2}$ 收敛，但对任意 $p>1$ 都有 $\lim_{x\to+\infty}\frac{x^p}{(x+2)\ln^2(x+2)}=+\infty$。
  - 仅 ② 正确 → 选 **（B）**。

### 母题 3：周期差函数方程求定积分（2023 年 1,2 · `p.56–57` 例 15）
> 设连续函数 $f(x)$ 满足 $f(x+2)-f(x)=x$，$\int_0^2 f(x)\,\mathrm{d}x=0$，则 $\int_1^3 f(x)\,\mathrm{d}x=$ ______。

- **【解1 · 构造平移变限积分秒杀（`p.57` 解 2）】**：
  - 令 $F(x)=\int_x^{x+2} f(t)\,\mathrm{d}t$，求导得 $F'(x)=f(x+2)-f(x)=x \implies F(x)=\frac{1}{2}x^2+C$。
  - 由已知 $F(0)=\int_0^2 f(t)\,\mathrm{d}t=0 \implies C=0$，故 $\int_1^3 f(x)\,\mathrm{d}x = F(1) = \frac{1}{2}$！
- **【解2 · 拆分换元兜底（`p.56` 解 1）】**：
  - $\int_1^3 f(x)\,\mathrm{d}x = \int_1^2 f(x)\,\mathrm{d}x + \int_2^3 f(x)\,\mathrm{d}x \xlongequal{x=t+2} \int_1^2 f(x)\,\mathrm{d}x + \int_0^1 [f(t)+t]\,\mathrm{d}t = \int_0^2 f(x)\,\mathrm{d}x + \int_0^1 t\,\mathrm{d}t = \frac{1}{2}$。
