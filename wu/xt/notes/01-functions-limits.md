## 一、本课定调 & 选填第一眼秒杀路由表

武忠祥《选填题》第一册开宗明义（`p.3`）：选择题丢分不是定理不会，而是**只会正面硬推、不会反例排除**。面对概念与极限选填，3 秒定型后必须坚持**“直接法（推演/几何/验证）× 排除法（特殊函数/赋值/几何）”双轨并行**。

| 第一眼触发特征 | 【解1】首选 / 秒杀路由 | 【解2】直接法严谨兜底 | 放行红线（0 分雷区） |
| :--- | :--- | :--- | :--- |
| **抽象复合函数性态 / 逆推解析式** | **赋值 / 取特例函数**（如 $f(x)=x,\sin x,e^x$）直接排掉 3 个选项 | 检查值域与定义域匹配，再反解或求导验证（`p.9–13`） | 反函数或复合代入前必须核对**单调区间与值域边界** |
| **奇偶 / 周期函数的原函数判断** | 直接套结论：**奇原必偶；偶原唯 $\int_0^x$ 奇；周期原查 $\int_0^T=0$** | 写 $F(x)=\int_0^x f(t)\,\mathrm{d}t+C$ 分段代换 $t=-u$ 或 $t=u+T$（`p.6–7`） | 连续偶函数的**任意**原函数未必奇（常数 $C$ 破坏奇性） |
| **抽象数列收敛/发散或海涅命题** | **极简震荡反例秒杀**：$x_n=(-1)^n,\ 2^{(-1)^n},\ \frac{1}{n\pi},\ 0$（`p.25,28`） | 用复合函数严格单调性（$f'=e^x+e^{-x}>0$）或定义证明 | 海涅定理数列趋于 $x_0$ 时**必须满足 $x_n\neq x_0$**（`p.28`） |
| **含未知 $f(x)$ 的极限求参/求值** | **排除法**：直接令已知极限的分子恒为 $0$ 反解特例 $f(x)$（`p.34`） | 恒等变形拆出已知极限块，或乘非零因子配凑（`p.34`） | 拆极限四则运算前，**必须确认拆出的每一块极限都存在** |
| **$n$ 项和 / $0/0$ 型极限填空** | 凑定积分定义（提 $\frac{1}{n}$）或洛必达 + 等价/泰勒（`p.36–46`） | 首尾同阶不可凑积分时，立即切**夹逼准则**（`p.39–40`） | 积分和式须核对每项 $f(\xi_i)$ 的**步长 $\frac{1}{n}$ 与区间端点** |

## 二、核心 `→ / ↛` 概念红线 & 极简反例库

| 命题推导方向 | 逻辑结论 | 武氏极简反例 / 板书实证 |
| :--- | :---: | :--- |
| 连续奇函数的**任意**原函数皆为偶函数 | **`→` 成立** | $F(x)=\int_0^x f(t)\,\mathrm{d}t+C$，常数 $C$ 为偶函数不破坏偶性（`p.6`）。 |
| 连续偶函数的**任意**原函数皆为奇函数 | **`↛` 打叉** | 反例：$f(x)=\cos x$，原函数 $\sin x + 1$ 非奇；仅 $\int_0^x f(t)\,\mathrm{d}t$ 必奇（`p.6`）。 |
| 连续 $T$-周期函数 $f$ 的原函数 $F$ 仍为 $T$-周期 | **充要条件** | **$F$ 周期 $\iff \int_0^T f(t)\,\mathrm{d}t = 0$**；反例 $f(x)=1+\cos x$（`p.7`）。 |
| $\{a_n\}$ 发散 $\longrightarrow \{f(a_n)\}$ 发散 | **需 $f$ 有反函数** | 若 $f$ 非单射则 **`↛`**：如 $f(x)=x+\frac{1}{x}$ 取 $a_n=2^{(-1)^n}$ 使 $f(a_n)\equiv\frac{5}{2}$ 收敛（`p.25`）。 |
| $\lim_{n\to\infty} x_n = 0,\ \lim_{n\to\infty} f(x_n)=A \longrightarrow \lim_{x\to 0}f(x)=A$ | **`↛` 打叉** | 仅一个序列极限无法控制全邻域：反例 $f(x)=\sin\frac{1}{x},\ x_n=\frac{1}{n\pi}$（`p.28`）。 |
| $\lim_{n\to\infty} x_n = 0,\ \lim_{x\to 0} f(x)=A \longrightarrow \lim_{n\to\infty}f(x_n)=A$ | **`↛` 打叉** | **缺 $x_n\neq 0$ 条件！** 反例 $f(x)=\frac{\sin x}{x}$（或分段改点值），取 $x_n\equiv 0$（`p.28`）。 |
| $\lim_{n\to\infty} f(n)=A \longrightarrow \lim_{x\to+\infty} f(x)=A$ | **`↛` 打叉** | 离散整数点极限不能控连续变量：反例 $f(x)=\sin(\pi x)$（`p.28`）。 |

## 三、高频选填母题双轨拆解

### 母题 1：发散数列复合判别（2024 年 2 · `p.25` 例 6）
> 已知数列 $\{a_n\}\ (a_n\neq 0)$，若 $\{a_n\}$ 发散，则必发散的是：  
> （A）$\{a_n+\frac{1}{a_n}\}$　（B）$\{a_n-\frac{1}{a_n}\}$　（C）$\{e^{a_n}+\frac{1}{e^{a_n}}\}$　（D）$\{e^{a_n}-\frac{1}{e^{a_n}}\}$

- **【解1 · 考场 15 秒排除秒杀】**：
  - 取震荡发散数列 $a_n=(-1)^n$：则 $a_n-\frac{1}{a_n}=0$、$e^{a_n}+e^{-a_n}=e+\frac{1}{e}$，立即排除 **（B）（C）**；
  - 取倒数配对发散数列 $a_n=2^{(-1)^n}$（即 $2,\frac{1}{2},2,\frac{1}{2},\dots$）：则 $a_n+\frac{1}{a_n}=\frac{5}{2}$ 恒常，排除 **（A）** → 秒选 **（D）**！
- **【解2 · 直接法严谨兜底】**：
  - 记 $f(x)=e^x-e^{-x}$，因 $f'(x)=e^x+e^{-x}>0$，故 $f$ 在 $\mathbb{R}$ 上严格单调递增且值域 $R_f=(-\infty,+\infty)$，存在单调反函数 $f^{-1}$。若 $\{f(a_n)\}$ 收敛于某 $A\in R_f$，则 $a_n=f^{-1}(f(a_n))\to f^{-1}(A)$ 收敛，与 $\{a_n\}$ 发散矛盾。故 **（D）必发散**。
- **【经典 0 分坑】**：只试 $a_n=n\to\infty$ 或只试 $a_n=(-1)^n$ 时，会误以为（A）也发散（因为 $(-1)^n+\frac{1}{(-1)^n}=2(-1)^n$ 恰好发散）；必须用 $2^{(-1)^n}$ 构造“倒数互换”反例才能击穿（A）。

### 母题 2：海涅定理与连续/离散极限辨析（`p.28` 例 9）
> 下列结论正确的是：  
> （A）若 $\lim_{n\to\infty}x_n=0$ 且 $\lim_{n\to\infty}f(x_n)=A$，则 $\lim_{x\to 0}f(x)=A$；  
> （B）若 $\lim_{n\to\infty}x_n=0$ 且 $\lim_{x\to 0}f(x)=A$，则 $\lim_{n\to\infty}f(x_n)=A$；  
> （C）若 $\lim_{n\to\infty}f(n)=A$，则 $\lim_{x\to+\infty}f(x)=A$；  
> （D）若 $\lim_{x\to+\infty}f(x)=A$，则 $\lim_{n\to\infty}f(n)=A$。

- **【解1 · 反例秒杀】**：
  - 取 $f(x)=\sin\frac{1}{x},\ x_n=\frac{1}{n\pi}$ 排 **（A）**；
  - 取 $f(x)=\frac{\sin x}{x}$（或 $0$ 处单独赋值的函数）与 **$x_n\equiv 0$**（违背去心邻域 $x_n\neq 0$）排 **（B）**；
  - 取 $f(x)=\sin(\pi x)$ 排 **（C）** → 秒选 **（D）**。
- **【解2 · 直接法】**：由连续归结（海涅定理）的必要方向，当 $x\to+\infty$ 极限为 $A$ 时，任意趋于 $+\infty$ 的序列 $x_n=n$ 必满足 $f(n)\to A$。

### 母题 3：已知抽象极限求另一极限（`p.34` 例 15）
> 已知 $\lim_{x\to 0}\dfrac{e^x f(x)+\tan x}{x^2}=0$，则 $\lim_{x\to 0}\dfrac{f(x)+x}{x^2}=$（　）  
> （A）$0$　（B）$1$　（C）$\frac{1}{3}$　（D）$\frac{2}{3}$

- **【解1 · 考场特殊函数秒杀（`p.34` 解 4）】**：
  - 直接令分子恒等于 $0$：$e^x f(x)+\tan x=0 \implies f(x)=-e^{-x}\tan x$。
  - 展开两项至二阶：$f(x)=-(1-x+o(x))(x+o(x))=-x+x^2+o(x^2)$，立刻得 $\lim_{x\to 0}\dfrac{f(x)+x}{x^2}=1$ → 选 **（B）**！
- **【解2 · 直接法乘因子/加减配凑（`p.34` 解 2/3）】**：
  - 两边分子分母同乘 $e^{-x}$ 得 $\lim_{x\to 0}\dfrac{f(x)+e^{-x}\tan x}{x^2}=0$。
  - 拆出目标式：$\dfrac{f(x)+x}{x^2}=\dfrac{f(x)+e^{-x}\tan x}{x^2}+\dfrac{x-e^{-x}\tan x}{x^2}$。
  - 因 $e^{-x}\tan x = x - x^2 + o(x^2)$，后项极限为 $1$，两项极限均存在，故原式 $=0+1=1$。
- **【经典 0 分坑】**：在未提取 $e^x$ 阶数时直接把 $e^x f(x)+\tan x$ 中的 $e^x$ 粗暴替成 $1$ 而丢掉一阶项 $-x$，会错算成（A）$0$。
