## 三、数二高数全模块「第一眼路由表」

> **手机端速查用法**：先看“第一眼触发特征”，3 秒内进“首选秒杀（解1）”；卡壳立刻切“兜底通解（解2）”；动笔前扫一眼“放行红线”。

### 模块 1：极限与无穷小（`17专题1-1/1-2/1-3/2/3/4`、`选填1/2`）

| 第一眼触发特征 | 首选秒杀（解1） | 兜底通解（解2） | 放行红线 |
| :--- | :--- | :--- | :--- |
| **$1^\infty$ 型幂指极限** | **$1^\infty$ 三步法**：化 $[1+\alpha]^{\beta} \to$ 算 $\lim\alpha\beta=A \to e^A$ | 改写 $e^{\beta\ln u}$，化为 $0\cdot\infty$ 再处理 | 含 $x$ 的幂指局部**禁先求底数极限**（`专题3 p.12`） |
| **$0/0$ 型含加减抵消** | **泰勒展开（Peano 余项）**直取最低阶非零项 | **加减放行后等价代换** + 单步洛必达 | 加减法代换前必须验 $\lim\frac{\alpha_1}{\beta_1}\neq \pm 1$（`专题2 p.17`） |
| **$\infty-\infty$ 根式差/分式差** | 根式差直接**有理化**；有分母直接**通分** | **提无穷因子**后用等价无穷小或泰勒 | 有理化注意共轭因子极限勿丢符号 |
| **$n$ 项和数列极限** | 提 $\frac{1}{n}$ 配 $\frac{k}{n}$ 走**定积分定义** | 无法凑均匀分割时，用**夹逼准则**放缩 | 首尾项比值同阶看夹逼，跨尺度同归看积分（`专题2 p.48,51`） |
| **递推数列 $x_{n+1}=f(x_n)$** | 判 $f$ 单调增/减定数列单调性 + **单调有界准则** | 若 $f$ 递减不单调，用**先猜极限 $A$ 再证 $|x_n-A|\le k|x_{n-1}-A|$** | 先假定极限存在求出 $A$，**必须反证收敛性**，绝不可循环论证（`专题3 p.41,47`） |
| **无穷小阶比较/定参** | **泰勒主部提取**（偶函数性质可先排奇次选项） | 求导定阶（洛必达一次降一阶）或等价替换 | 变限积分先看积分上下限阶数与被积函数最低阶和（`专题4 p.4–5`） |

### 模块 2：导数定义、中值定理、根、不等式与性态（`17专题5/8/9`、`选填2/3`）

| 第一眼触发特征 | 首选秒杀（解1） | 兜底通解（解2） | 放行红线 |
| :--- | :--- | :--- | :--- |
| **一点可导性 / $|x-a|\varphi(x)$** | **口诀秒杀**：$\varphi(x)$ 连续时，$|x-a|\varphi(x)$ 在 $a$ 可导 $\iff \varphi(a)=0$（`选填2 p.28`） | 分别算左导数 $f'_-(a)$ 与右导数 $f'_+(a)$ | 注意分母写成 $f(x)-f(a)$ 时，若去心邻域可能取 $0$ **禁直接作分母**（`选填2 p.34`） |
| **极限形式凑 $f'(x_0)$** | 走“**一静一动** + 分子差配分母增量”框架直接辨识 | 构造特例函数（如分段震荡 $x^2\sin\frac{1}{x}$）排除 | 双动点极限（如 $\frac{f(x_0+h)-f(x_0-h)}{2h}$）存在 $\not\to f'(x_0)$ 存在 |
| **存在 $\xi$ 使 $F'(\xi)=0$ / 微分等式** | 逆推**辅助函数**（如 $e^xf(x), x^kf(x)$）用罗尔定理 | 积分还原法找原函数，再配端点值 | 端点条件不足先找“隐含零点”，区间内 $n$ 个根至少给导数留 $n-1$ 个根 |
| **方程根的个数** | **存在性**（零点定理）+ **唯一性**（单调性 / 罗尔推论） | 求导找极值点，画草图比极值符号与端点极限 | 开区间端点取极限异号同样可用零点定理（`专题9 p.2`） |
| **函数/积分不等式** | 移项构造函数查**单调性 / 最值**；多阶条件用**泰勒展开** | **拉格朗日中值**或**凹凸性（Jensen）**切线放缩 | 变限积分不等式优先将常数上限改为变量 $x$（`专题8 p.3`） |
| **极值 / 拐点判别（选填）** | 若给出显式/对称变限积分，先看**奇偶性 + 首项泰勒阶数**（`选填3 p.49–50`） | 第一/二充分条件；隐式方程用**求导保号性** | 可导函数**极值点与拐点绝不同时出现**；$f''(x_0)$ 未必存在才是拐点（`选填3 p.47,50`） |

### 模块 3：积分计算、变限积分与反常积分（`17专题10`、`选填4`）

| 第一眼触发特征 | 首选秒杀（解1） | 兜底通解（解2） | 放行红线 |
| :--- | :--- | :--- | :--- |
| **不定积分基础/乘积型** | **凑微分（第一换元）**优先；“反对幂三指”跨类乘积用**分部积分** | 含 $\sqrt{a^2\pm x^2}$ 走三角代换；一般有理分式拆**部分分式** | 三角有理式先看奇偶对称性（`专题10 p.5`），最后不得已再用万能代换 $t=\tan\frac{x}{2}$ |
| **对称区间 / 三角高次定积分** | **奇零偶倍** + 周期平移 + **Wallis 点火公式**（`选填4 p.41`） | 区间再现 $x=a+b-t$ 或分部递推 | **禁跨原函数间断点直接代牛顿-莱布尼茨**（`专题10 p.23`） |
| **变限积分 $\int_a^x f(t)dt$ 性态** | 直接套**连续 $\to$ 可导 / 可去 $\to$ 可导 / 跳跃 $\to$ 连续不可导**（`选填4 p.20`） | 被积含 $x$ 先换元 $u=xt$（或 $x-t$）剥离 $x$ 再求导 | 不可直接对 $\int_a^x g(x,t)dt$ 内层的 $x$ 漏求偏导 |
| **反常积分敛散性** | **拆奇点分段** + 抓无穷/瑕点同阶 $p$-积分比较 | 定义求极限或凑微分显式积出 | 无界瑕点与无穷限必须**各自独立收敛**，合写发散不能抵消（`选填4 p.33`） |

### 模块 5：微分方程 ODE（`17专题12`、`选填5`）

## 四、高频「单向箭头 `→` vs 反向打叉 `↛`」与极简反例速查表

> **概念选择题生命线**：考研选填中概念辨析题 80% 的陷阱都在把“单向成立”偷换成“充要成立”。每记牢一行，考场直接秒杀一个选项！

### 1. 极限、保号性与局部导数（`选填1 p.20–24`、`选填3 p.39–44`）

| 命题推导方向 | 逻辑结论 | 极简反例 / 武氏评注 |
| :--- | :--- | :--- |
| 数列 $\{x_n\}$ 收敛 $\longrightarrow$ 有界 | **`→` 成立** | 反向 **`↛`**：$x_n=(-1)^n$ 有界但不收敛。 |
| $x_n > 0$ 且 $\lim_{n\to\infty} x_n = A \longrightarrow A > 0$ | **`↛` 打叉** | 反例：$x_n=\frac{1}{n}>0$，但 $A=0$（极限保号只能保证 $A\ge 0$）。反之 $A>0 \to$ 充分大项 $x_n>0$。 |
| $\lim x_n = a \longrightarrow \lim |x_n| = |a|$ | **`→` 成立** | 反向 **`↛`**：$x_n=(-1)^n$ 满足 $|x_n|\to 1$ 但原数列发散（**仅 $a=0$ 时充要**）。 |
| $f'(x_0) > 0 \longrightarrow f(x)$ 在 $x_0$ 某邻域单调增 | **`↛` 打叉** | 反例：$f(x)=x+2x^2\sin\frac{1}{x}\ (x\neq 0), f(0)=0$，$f'(0)=1>0$ 但在 $0$ 任意邻域导数变号（若加 **$f''(x_0)$ 存在**使 $f'$ 在 $x_0$ 处连续则 **`→` 成立**，`选填3 p.44`）。 |
| $\lim_{x\to x_0} f'(x)=A \longrightarrow f'(x_0)=A$ | **`→` 需前提** | 需已知 **$f$ 在 $x_0$ 连续**（导数极限定理）方成立；若在 $x_0$ 间断则不成立（可去间断函数）。 |

### 2. 奇偶性、周期性与原函数（`选填1 p.6–7`、`选填4 p.31`）

| 命题推导方向 | 逻辑结论 | 极简反例 / 武氏评注 |
| :--- | :--- | :--- |
| 连续奇函数的**任意**原函数皆为偶函数 | **`→` 成立** | 任意原函数 $F(x)=\int_0^x f(t)dt + C$，加常数 $C$ 不破坏偶性。 |
| 连续偶函数的**任意**原函数皆为奇函数 | **`↛` 打叉** | 反例：$f(x)=\cos x$，原函数 $\sin x + 1$ 非奇函数；**仅 $\int_0^x f(t)dt$ 必为奇**（`选填1 p.6`）。 |
| 可导 $T$-周期函数的导函数必为 $T$-周期函数 | **`→` 成立** | 两边求导即得；但连续 $T$-周期函数的**原函数必为周期函数** **`↛` 打叉**。 |
| 连续 $T$-周期函数 $f$ 的原函数 $F$ 为 $T$-周期函数 | **充要条件** | **$F$ 周期 $\iff \int_0^T f(t)dt = 0$**（反例：$f(x)=1+\cos x$，$F(x)=x+\sin x$ 不周期，`选填1 p.7`）。 |

### 3. 可积、连续、可导与反常积分（`选填3 p.26`、`选填4 p.20, 39`）

| 命题推导方向 | 逻辑结论 | 极简反例 / 武氏评注 |
| :--- | :--- | :--- |
| $f$ 在 $[a,b]$ 可导 $\to$ 连续 $\to$ 可积 | **单向 `→`** | 反向全 **`↛`**：$|x|$ 连续不可导；$\operatorname{sgn}(x)$ 有限间断可积不连续。 |
| $f$ 在 $[a,b]$ 可积 $\longrightarrow F(x)=\int_a^x f(t)dt$ 连续 | **`→` 成立** | 但 $F(x)$ **`↛` 必可导**（跳跃间断点处左右导数不等）；在可去间断点处 $F$ 可导且 $F'(x_0)=\lim_{x\to x_0}f(x)\neq f(x_0)$，故 $F$ 仍**不是** $f$ 的原函数！（`选填4 p.20`） |
| $f$ 在 $[a,b]$ 存在原函数 $\longrightarrow f$ 连续 / 可积 | **`↛` 打叉** | 原函数存在无需连续，且达布（导数）函数可震荡无界导致不可积；反之 **连续 $\to$ 必有原函数**。 |
| 非负连续 $f$ 使 $\int_0^{+\infty}f(x)dx$ 收敛 $\to \lim_{x\to+\infty}f(x)=0$ | **`↛` 打叉** | 可构造等高越来越窄的“尖峰”脉冲函数使积分有限但极限不存在。 |
| 非负连续 $f$ 使 $\int_0^{+\infty}f(x)dx$ 收敛 $\to \int_0^{+\infty}f^2(x)dx$ 收敛 | **`↛` 打叉** | 尖峰反例同上（高平方后面积反发散）；另 $\exists p>1$ 使 $\lim_{x\to+\infty}x^pf(x)$ 存在亦 **`↛`**（反例 $f(x)=\frac{1}{x\ln^2 x}$ 在 $[2,+\infty)$ 收敛，2024 数二，`选填4 p.39`）。 |

### 4. 极值与拐点（`选填3 p.39, 47, 50`）

| 命题推导方向 | 逻辑结论 | 极简反例 / 武氏评注 |
| :--- | :--- | :--- |
| $f$ 在 $x_0$ 取极大值 $\longrightarrow f$ 在左邻域增、右邻域减 | **`↛` 打叉** | 反例：$f(x)=2-x^2(2+\sin\frac{1}{x})\ (x\neq 0), f(0)=2$，是严格极大值点却在任意邻域震荡不单调（`选填3 p.39`）。 |
| $f$ 在 $x_0$ 可导，且取极值 $\longrightarrow (x_0,f(x_0))$ 非拐点 | **`→` 成立** | 可导点处极值与拐点**互不相容**（`选填3 p.50`）；若**不可导**则可兼得（如 $x\le 0$ 取 $x^2$，$x>0$ 取 $\sqrt{x}$，$(0,0)$ 既是极小值点又是凹凸分界拐点）。 |
| $(x_0,f(x_0))$ 是拐点 $\longrightarrow f''(x_0)=0$ | **`↛` 打叉** | 可能 $f''(x_0)$ 不存在（反例：$y=x^{1/3}$ 在 $0$ 处切线垂直）。反之 $f''(x_0)=0 \not\to$ 拐点（反例：$y=x^4$）。 |

### 5. 多元连续、偏导与可微（`选填5 p.22–28`）

| 命题推导方向 | 逻辑结论 | 极简反例 / 武氏评注 |
| :--- | :--- | :--- |
| 两个累次极限存在且相等 $\longrightarrow$ 二重极限存在 | **`↛` 打叉** | 反例：$f(x,y)=\frac{xy}{x^2+y^2}$ 在 $(0,0)$ 累次极限皆为 $0$，但沿 $y=kx$ 极限为 $\frac{k}{1+k^2}$ 不存在。 |
| 二元函数连续 $\longrightarrow$ 偏导数存在 | **`↛` 打叉** | 反例：$f(x,y)=\sqrt{x^2+y^2}$ 在 $(0,0)$ 连续但两偏导不存在。 |
| 偏导数存在（甚至连续与偏导同时成立）$\longrightarrow$ 可微 | **`↛` 打叉** | 偏导存在 $\not\to$ 连续（$\frac{xy}{x^2+y^2}$ 补 $0$）；连续且偏导存在仍 $\not\to$ 可微（反例：$f(x,y)=\sqrt{|xy|}$ 在 $(0,0)$ 沿 $y=x$ 不可微）。 |
| 一阶偏导在 $(x_0,y_0)$ **连续** $\longrightarrow$ 在该点可微 | **`→` 成立** | 反向 **`↛`**：可微未必偏导连续（例：$(x^2+y^2)\sin\frac{1}{\sqrt{x^2+y^2}}$ 补 $0$）。 |
| 二阶混合偏导 $f_{xy}, f_{yx}$ 存在 $\longrightarrow f_{xy}=f_{yx}$ | **`↛` 打叉** | 需混合偏导连续才相等；经典 Peano 反例 $f(x,y)=xy\frac{x^2-y^2}{x^2+y^2}\ ((x,y)\neq(0,0)),\ f(0,0)=0$ 满足 $f_{xy}(0,0)=-1\neq 1=f_{yx}(0,0)$（另见 `选填5 p.28` 2020 数二分段函数按定义判 $f_{xy}(0,0)$ 不存在）。 |

## 五、武氏板书铁律与经典「0分错法」警示录（实证页码）

### 1. 洛必达降阶铁律：`17堂课专题2（板书）.pdf p.40` & `26高数17堂课专题1-2（板书）.pdf p.10`
- **题目**：设 $f(x)$ 二阶可导，$f(0)=0, f'(0)=2, f''(0)=1$，求 $\lim_{x\to 0}\frac{f(x)-2x}{x^2}$。
- **0分错法**：$\lim_{x\to 0}\frac{f(x)-2x}{x^2} = \lim_{x\to 0}\frac{f'(x)-2}{2x} = \lim_{x\to 0}\frac{f''(x)}{2} = \frac{f''(0)}{2} = \frac{1}{2}$。
- **板书铁律**：**“经典的错误，标准的 0 分！”** 仅知“$n$ 阶可导”，不能保证 $f^{(n)}$ 连续或极限存在。洛必达法则**最多用到 $f^{(n-1)}(x)$**，最后一步必须回归**导数定义**：$\lim_{x\to 0}\frac{f'(x)-f'(0)}{2x}=\frac{1}{2}f''(0)=\frac{1}{2}$；仅当明确**“$n$ 阶连续可导”**时方可用到 $f^{(n)}(x)$。

### 2. 幂指局部禁先求极限：`17堂课专题3（板书）.pdf p.12`
- **题目**：求 $\lim_{x\to +\infty}\frac{\int_1^x e^{t^2+\frac{1}{t^2}}dt}{\int_1^x \left(1+\frac{1}{t^2}\right)^{t^4}dt}$。
- **0分错法**：洛必达一次得 $\lim_{x\to+\infty}\frac{e^{x^2+\frac{1}{x^2}}}{\left(1+\frac{1}{x^2}\right)^{x^4}}$，随后把分母局部写成 $\left[\left(1+\frac{1}{x^2}\right)^{x^2}\right]^{x^2}\to e^{x^2}$，得出 $\lim \frac{e^{x^2+\frac{1}{x^2}}}{e^{x^2}}=1$。
- **板书铁律**：**“经典的错误，标准的 0 分！”** 含变量的幂指因子在整体极限未脱壳前，**绝不能仅对内层底数先求极限再继续保留外层指数**！正解：化底指数 $\frac{e^{x^2}}{e^{x^4\ln(1+\frac{1}{x^2})}}\cdot e^{\frac{1}{x^2}} = e^{x^2 - x^4\left(\frac{1}{x^2}-\frac{1}{2x^4}+o(\frac{1}{x^4})\right)}\cdot e^{\frac{1}{x^2}} \to e^{\frac{1}{2}}$。

### 3. 等价无穷小加减放行铁律：`17堂课专题2（板书）.pdf p.17`
- **板书铁律**：乘除法直接换；加减法 $\alpha\pm\beta$ 代换为 $\alpha_1\pm\beta_1$（已知 $\alpha\sim\alpha_1,\beta\sim\beta_1$）的**充分放行条件**为：$\lim\frac{\alpha_1}{\beta_1}=A\neq 1$（减法）或 $A\neq -1$（加法）时直接放行；若比值为 $1$ 或 $-1$，切忌盲目替换，须立刻切泰勒展开核验！

### 4. 定积分跨奇点直接牛顿-莱布尼茨必 0 分：`17堂课专题10（板书）.pdf p.23`
- **题目**：计算 $\int_0^{2\pi}\frac{dx}{1+\cos^2 x}$。
- **0分错法**：$\int_0^{2\pi}\frac{d\tan x}{2+\tan^2 x} = \frac{1}{\sqrt{2}}\arctan\frac{\tan x}{\sqrt{2}}\Big|_0^{2\pi} = 0$。
- **板书铁律**：**“经典的错误，标准的 0 分！”** $\tan x$ 在 $(0,2\pi)$ 内 $x=\frac{\pi}{2},\frac{3\pi}{2}$ 处无定义（原函数跨奇点跳变），绝不可直接代上下限。正解：用周期 $\pi$ 与奇偶对称性拆为 $4\int_0^{\frac{\pi}{2}}\frac{dx}{1+\cos^2 x} = \frac{4}{\sqrt{2}}\arctan\frac{\tan x}{\sqrt{2}}\Big|_0^{\frac{\pi}{2}^-} = \sqrt{2}\pi$。

### 5. 抽象极限硬拆配凑忽略分母取零：`26选填题（2）板书.pdf p.34`
- **题目**（2020 年 3）：设 $\lim_{x\to a}\frac{f(x)-a}{x-a}=b$，求 $\lim_{x\to a}\frac{\sin f(x)-\sin a}{x-a}$。
- **0分/扣分错法**：直接写成 $\lim_{x\to a}\frac{\sin f(x)-\sin a}{f(x)-a}\cdot\frac{f(x)-a}{x-a}=b\cos a$。
- **板书铁律**：**“经典错误”**——当 $b=0$ 时，无法保证在 $a$ 的去心邻域内 $f(x)-a\neq 0$（甚至可能恒为 $a$ 或震荡过 $a$）。正解：用拉格朗日中值定理化为 $\lim_{x\to a}\cos\xi\cdot\frac{f(x)-a}{x-a}=b\cos a$，或令 $F(x)=\begin{cases}f(x),&x\neq a\\ a,&x=a\end{cases}$ 对复合函数 $\sin F(x)$ 在 $x=a$ 求导。

### 6. 网传递推收敛口诀与 $AC-B^2=0$ 边界：`17堂课专题3（板书）.pdf p.48` & `17堂课专题14（板书）.pdf p.2,5`
- **板书铁律**：
  - 递推数列 $x_{n+1}=f(x_n)$ 用压缩映射（$|f'(x)|\le k < 1$）判收敛时，**缺一不可**：必须满足严格界 **$k<1$**（仅 $|f'(x)|<1$ 不够，如 $f(x)=x+\frac{1}{1+e^x}$）且在不变闭区间或全局 $\mathbb{R}$ 上成立，考场大题需完整写出 $|x_{n+1}-a|\le k|x_n-a|\le k^n|x_1-a|\to 0$。
  - 二元极值算到 $AC-B^2=0$ 时**不可轻言“无极值”**，必须回到**极值定义**（如 `17堂课专题14（板书）.pdf p.2` 明确写明“一般用定义判定”，`p.5` 则示范用局部保号与泰勒展开直接按定义判极小值）。
