# 真题 HTML 排版依据

目标是尽量还原考试真题原卷，方便阅读与做题。验收标准首先是原卷的真实写法，不能把用户指出的一个视觉疑点孤立地变成全局排版硬规则，也不能把渲染引擎默认值直接等同于原卷。

## 依据优先级

1. 已确认来源的对应年份原卷扫描或照片：对照同一道题的符号、上下限、间距、字号层级与换行。
2. 原卷缺失时，使用来源明确的出版或重排版本作辅助；明确标注其并非原卷，不用它证明“原卷如此”。
3. 无可靠参考时，以数学排版惯例和用户指出的可读性问题判断。KaTeX 原生排版可以作为候选起点，仍须检查紧凑程度、清晰度、遮挡及溢出。

## 积分上下限

先核对原卷，不预设必须竖直对齐或必须倾斜。上限、下限应与积分号保持合理紧凑的关系，不能因人为压缩间距而重叠。终端文字示意的观感不作为 HTML 字形排版依据。

目前已撤销造成重叠的间距压缩，也撤销后来为竖直对齐添加的额外覆盖，恢复 KaTeX 原生字形间距作为待原卷核验的候选。自动检查通过，只能证明所检查的渲染与版式条件满足，不能证明已经复刻原卷。

## 变更与交付

审查记录应区分原卷已核对的事实、辅助来源支持的判断、尚未确认的候选。不得把本项目自己生成的 PDF 当作原卷来相互验证。

先审查 HTML 与生成链路，分批提交源码、依据和进度。版式确定后再统一更新题图与 PDF，避免重复生成与返工。
