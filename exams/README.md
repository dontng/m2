# 数学（二）历年真题

2010—2026 年，17 套、385 题。用于个人学习与打印训练的非官方转写稿，不含答案解析，不宣称复刻考场原卷。

## 阅读与打印

打开 `index.html` 进入年份目录，`years/2010.html` 至 `years/2026.html` 为年度试卷，`all.html` 为合订本。下载整个 `exams/` 文件夹后可离线阅读，公式、字体和附图不依赖 CDN。打印使用 A4、100% 缩放，关闭浏览器自带页眉页脚。

## 后续修改入口

- `data/2010.json` 至 `data/2026.json`：唯一题目源数据，包含题号、题型、题干、选项、分值和附图路径。公式保留 `$...$` / `$$...$$` LaTeX 源码。
- `assets/exam.css`：所有年份共用的正文、卷头、选项网格与打印样式。
- `assets/exam.js`：选项宽度适配，优先降列，不缩小公式。
- `scripts/build.cjs`：从年度 JSON 生成语义化 HTML，构建时用 KaTeX 校验全部公式，浏览器用本地 KaTeX 渲染。
- `assets/figures/`：题内示意图。
- `assets/vendor/katex/`：固定版本的 KaTeX 及其字体与许可。
- `SOURCES.md`：来源、已知修正和校勘范围。

修改数据或生成代码后，在仓库根目录执行：

```sh
node exams/scripts/build.cjs
```

无需 npm install。脚本会检查题号连续、每题四个选项、每年总分 150 分和全部公式能否编译。不要只改生成 HTML：下一次构建会覆盖它。

## 反馈方式

题目问题注明“年份＋题号”，排版问题注明“年份＋题号＋屏幕/打印”。公共排版调整会应用于所有年份；个别选项需要固定列数时，修改该题的 `layout` 为 `4col`、`2col` 或 `1col`。

尚未完成 385 题与官方出版物的逐字校勘。结构检查和分值检查不能替代题目内容校对。

## PDF 导出

`pdf/` 内是 2010—2026 年 17 份年度 PDF，每份 4 页，共 68 页。保留当前 HTML 打印样式，适合用于检查字号、留白、题号及公式排布。每份同名 JSON 记录页数、公式渲染与版面检查结果。

需要重新导出时，先安装 Playwright，再执行：

```sh
node exams/scripts/export-pdf.cjs 2010 2026
```

可用 `CHROMIUM_PATH` 指定已有 Chromium/Chrome 可执行文件。导出会等待字体、公式和附图加载，检测未渲染源码和版面溢出。
