# 数学（二）章节题单

2010—2026年，385道完整真题，25章。线性代数在前，高等数学在后；各章按年份从新到旧（2026→2010），同年按原题号升序。

提供 **Markdown (.md)** 与 **网页版 (.html)** 双格式，公式规范化（`\limits` 上下标对齐），支持随时阅读、编辑与本地做题。

## 提速提效与考点导引

- **双格式支持**：所有 25 章均提供配套的 `.md` 与 `.html`，Markdown 保持紧贴 HTML 同级存放，公式经排版优化确保下标严格置于正下方。

- **题头考点导引**：精选 106 处开篇重难题与易踩坑题，在题头提供 2 行以内的白话点拨（心理预期与关键招式）；常规直接计算题保持纯净留白。

- **网页版交互增强**：支持顶部年份快速跳转（平滑滚动）、题型统计胶囊、悬浮回顶及打印自适应格式。

## 构建方式

```sh
python3 -m pip install -r chapters/scripts/requirements.txt
python3 chapters/scripts/build.py
```

构建会同时生成 25 章 HTML 与 Markdown，检查 385 题无漏收、无重复主归属、年份倒序，以及题目正文、公式和附图一致性。
