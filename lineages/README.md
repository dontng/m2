## 编写与验收规范

- **写作顺序**：开篇给出面对题型的真实判断顺序与决策表；讲到关键判断时直接嵌入真题原图，将第一步、触发条件、限制、完整推演（选择题含关键干扰项拆解，解答题按分问写全）与条件变式检验放在同一处。
- **验收三原则**：题设与计算能否对照原卷、读者能否说出为什么从这一步入手、改一个条件后能否重新判断。
- **回练与过关**：每篇末尾配少量真题回练（默认折叠核对要点）与明确的过关标准；其余年份同题型可按表内章节链接回[章节题单](../chapters/README.md)继续刷题。
